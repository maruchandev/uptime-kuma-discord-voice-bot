FORMAT

グループと読みを登録

entriesの各監視名にreading（読み）とgroup（グループ名）を登録します。必要ならgroupsに正規表現の既定グループも設定できます。監視対象ごとのgroupが優先されます。

{
  "groups": {
    "^CK-.*-V001-": "第1教室"
  },
  "entries": {
    "CK-AP-V001-1": {
      "reading": "アクセスポイント ブイゼロゼロイチ いち",
      "group": "教室１０１"
    }
  }
}
entriesのgroupが空ならgroupsの正規表現を使います。以前の「監視名: 読み」形式も読み込めます。
